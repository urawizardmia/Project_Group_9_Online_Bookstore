## Team Members

## Project Description
An online bookstore where users can browse books, view book details, search for books, and leave reviews and ratings.

## Technologies
- React
- Node.js
- Express.js
- PostgreSQL

## Database Setup
1. Install PostgreSQL
2. Create a database named online_bookstore
3. Import database/online_bookstore.sql into the database

The database contains 60 sample books

## Backend Setup
1. Open the backend folder in Terminal
2. Run npm install
3. Run node index.js

The backend runs at http://localhost:3000

## Frontend Setup
1. Open the frontend folder in Terminal
2. Run npm install
3. Run npm run dev

The frontend runs at http://localhost:5173

## API Routes
- GET /books - Returns all books
- GET /books/:id - Returns a single book
